# Fixed text fixture

`NotoSansCJKsc-fixture.otf` is a subset of Noto Sans CJK SC Regular, version
2.004 (face 2 of the upstream regular collection). It contains the characters in
`corpus.txt`, plus shaping closure generated by HarfBuzz. It is not a complete
CJK font. The font's embedded copyright and naming records are retained. The
font remains under the SIL Open Font License in `OFL.txt`.

Embedded copyright: Copyright 2014-2021 Adobe (http://www.adobe.com/).

Upstream: <https://github.com/notofonts/noto-cjk/tree/main/Sans>

Source collection SHA-256:
`b76b0433203017ca80401b2ee0dd69350349871c4b19d504c34dbdd80541690a`

Subset SHA-256:
`b3b223d3240c2f7b00c26ca4418a95b12d064584f473b25e9b590c296badd29c`

The subset is 25,780 bytes. Reproduce from the matching source collection using
HarfBuzz 14.1.0, from this directory:

```sh
hb-subset NotoSansCJK-Regular.ttc --face-index=2 \
  --text-file=corpus.txt --name-IDs='*' --name-languages='*' \
  --output-file=NotoSansCJKsc-fixture.otf
```

Tests and fixed-font experiments load this subset explicitly. Expanding their
corpus requires regenerating the asset and its checksum.
